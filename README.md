# 📝 AnotaMix

O **AnotaMix** é uma aplicação web desenvolvida para facilitar a organização e o gerenciamento de anotações pessoais, oferecendo uma interface simples, intuitiva e funcional.

## 🚀 Funcionalidades

- Criar, visualizar, editar e excluir anotações (CRUD).
- Organizar anotações por assunto: Estudos, Trabalho, Casa e Pessoal.
- Classificar anotações por nível de relevância.
- Registrar automaticamente data e hora.
- Validar os campos obrigatórios do formulário.

## 🛠️ Tecnologias utilizadas

- **HTML5** — Estrutura da aplicação.
- **CSS3** — Estilização e interface.
- **JavaScript** — Funcionalidades e manipulação do DOM.

## 💻 Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Comece a criar e organizar suas anotações.

## 🎯 Objetivo

Projeto desenvolvido para colocar em prática conhecimentos de desenvolvimento web, lógica de programação, manipulação do DOM e operações CRUD utilizando JavaScript.
